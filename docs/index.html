What it does

A clipboard that keeps up with you.

Windows remembers the last thing you copied. Cliptack remembers all of it, and makes it fast to get back from the keyboard.

Search like a developer

Prefix search over everything, plus operators when you want them: app:Code type:code is:pinned folder:work sort:used "exact phrase". A pasted URL is never mistaken for an operator.

Paste as

Ctrl+T prettifies or minifies JSON, decodes base64, URL-encodes, and changes case. Only the paste changes; the history keeps what you actually copied, key order included.

Tack it to your screen

Ctrl+O pops a clip — a snippet, an image, a colour — into a small card that stays on top, instantly. Ctrl+Shift+N starts a blank one, and the tray hides them all at once. Notes stay editable in the card, and cards come back after a restart.

Private by design

Your clipboard sees everything. So it stays on your machine.

Passwords, addresses, half-written messages: a clipboard history is a record of everything you've handled. Cliptack treats it that way.

01

Nothing leaves your machine.

The code makes no network calls, and no dependency that opens a socket is included. No account, no sync, no telemetry.

Password ••••••••✓ pasted
Message ✕ refused
02

Passwords paste only into password fields.

Saved credentials are encrypted with Windows DPAPI. Ctrl+Shift+Enter pastes one only after Windows UI Automation confirms the focused box is a password field. Anything else, and nothing is sent.

03

Hidden from screen shares.

On by default, the panel and every sticky are excluded from screen capture, so your history never turns up in a meeting.
